# IceMaker

Open-source IoT platform for data collection, processing, visualization, and device management.

</div>

IceMaker is developed and maintained by [AACC](https://aacc-ai.com). It is built on top of the open-source [ThingsBoard](https://github.com/thingsboard/thingsboard) IoT platform (Apache License 2.0) — see [NOTICE](./NOTICE) for full attribution and a summary of the modifications made.

## ✨ Features

- **Device & asset management** — provision, monitor, and control IoT entities with rich server-side APIs; define relations between devices, assets, customers, and other entities.
- **Real-time dashboards** — collect and store telemetry data in a scalable, fault-tolerant way; visualize it with built-in or custom widgets and flexible dashboards.
- **SCADA dashboards** — monitor and control industrial processes in real time using SCADA symbols to build and manage any workflow.
- **Rule engine** — build data-processing rule chains, transform and normalize device data, and raise alarms on telemetry events, attribute updates, or device inactivity.
- **Notifications** — alert via email, SMS, mobile push, or third-party integrations.
